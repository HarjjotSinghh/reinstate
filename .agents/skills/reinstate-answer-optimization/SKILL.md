# Reinstate Answer Optimization

## Goal

Make each important question easy to answer accurately from the page.

## Workflow

1. Identify the user's exact question.
2. Put a direct answer immediately below the H1 or question heading.
3. Keep the first answer concise but complete.
4. expand with:
   - prerequisites
   - steps
   - expected output
   - exceptions
   - limitations
   - security notes
   - troubleshooting
5. use tables for explicit comparisons.
6. use numbered lists for ordered tasks.
7. use bullets for unordered facts.
8. define unfamiliar terms.
9. add contextual internal links.
10. verify that extracted paragraphs retain correct meaning.

## Direct-answer rules

- answer the question in the first sentence
- name Reinstate only when relevant
- include current supported agents or platforms only when necessary
- state conditions and limitations
- avoid hype
- avoid unsupported superlatives
- avoid filler introductions
- do not repeat the same FAQ across every page

## Test

For each answer block, ask:

- Is it correct alone?
- Is its subject explicit?
- Is the version or condition clear?
- Could an assistant cite it without distorting it?
- Does the next section provide evidence?
