# Phase 5 universal agent coverage report template

`PHASE5-DEVICE-REPORT-V1`

Copy this template into exactly one device-owned report. Keep it cumulative,
sanitized, and append-only: preserve failures and add targeted rechecks as new
evidence. Never commit transcript text, prompts, responses, capsule bodies,
credentials, configuration values, private paths, repository names, filenames,
diffs, or raw child-process output.

Allowed report paths:

- `docs/testing/results/REPORT_DATE-macos-phase5-CANDIDATE.md`; and
- `docs/testing/results/REPORT_DATE-windows-phase5-CANDIDATE.md`.

Only the macOS coordinator report may add the final reconciliation block, after
independently verifying both immutable device-report commits.

The contract this report satisfies is
[../phase-5-universal-agent-coverage-acceptance.md](../phase-5-universal-agent-coverage-acceptance.md).

## Verdict

- **Device verdict:** `PASS | FAIL`
- **Milestone:** `SETUP | ARTIFACT_VERIFIED | MATRIX_COMPLETE | RECONCILED`
- **Matrix generated by:** `rein doctor --agents --acceptance-matrix`
- **Required counts:** `0 PASS / 0 PARTIAL / 0 FAIL / N NOT TESTED`
- **Release-blocking findings:** `0`

`PARTIAL` and `NOT TESTED` do not pass a required row. A missing required
result is `FAIL`.
