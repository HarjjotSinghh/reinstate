## 8. Findings and repository hygiene

### Release-blocking

1. Flagship A1/A2/A3/A5/A6/A7 did not complete a new destination session acknowledgement on this host (throwaway Claude not logged in; Codex PTY produced 87 bytes and no acknowledgement).
2. Installed Grok-sourced dry-run (E5/E6) exits 5 `environment preflight is blocked` because `agentcheck` has no Grok definition, so layout is unrecognized and ReadOnly preflight still blocks. Busy-check no longer returns exit 1 `unsupported agent "grok"`.
3. C5 Windows os-roots fixture does not remap a recorded Windows workspace onto the live macOS checkout; preflight blocks.
4. R4: a hanging source `--version` wrapper did not return `UNTESTED` / exit 5 within 25 s (empty output / runner timeout). Timed-out probe was not classified Compatibility in this harness.

### Non-blocking

- Host Claude is `2.1.228`, not `2.1.229`. Range includes 2.1.229 via C8 fail-closed on `2.1.230`.
- Destination Codex/Claude Detect returns UNTESTED until the isolated home contains `sessions/` or `projects/`; empty override dirs must include those layout directories.
- OpenCode warning `agent_not_installed` on `sessions --json` is expected.

### Test-harness deviations and supersessions

- Isolated Claude print-mode session failed closed (not logged in); no operator `.claude` tree was read.
- A1 used Python PTY with `TERM=xterm-256color`; destination TUI emitted 87 bytes.
- `goreleaser build --snapshot --single-target` left the worktree clean.
- No rc.1 or rc.2 corpus reused.
