2. `go mod tidy -diff` fails on the tagged commit (`pflag` direct vs indirect).
3. Installed Grok source handoff exits 1 `unsupported agent "grok"` (E5/E6). Optional installed-vendor FAIL is a candidate blocker.
4. R1: source executable removed from PATH → exit 5 compatibility block, not layout-only SUPPORTED.
5. R4 (timed-out version probe) was not executed.
6. C4 did not refuse a different-repository cwd.
7. C2/C5/C6/C7 missing or failed.
8. B3/B6 did not prove checkpoint-zero-verbatim or all five fidelity classes.
9. F7 collision not constructed; F8 did not fail closed before spawn.

### Non-blocking

- Host Claude is `2.1.228`, not `2.1.229`. Range includes 2.1.229 via C8 fail-closed on `2.1.230`.
- Top-level `rein list` ignores `CLAUDE_CONFIG_DIR` (adapter Discover). `sessions`/`handoff` honor it.
- `--no-redact` is an unknown flag (still exit 2).
- Context-mode sandbox `TMPDIR` inside a git repo made `make verify` fail until rerun on the host.

### Test-harness deviations and supersessions

- First `rein list` in a sandbox leaked default Claude inventory into the agent context. Home destroyed; isolation restarted. Those identifiers are not committed.
- `goreleaser build --snapshot` briefly modified `go.mod`; reverted; not committed.
