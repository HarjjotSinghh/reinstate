## 21. Harness defects (merged, non-blocking to the mechanism under test)

- **Host paging-file exhaustion under concurrent background jobs (part
  A).** Running the unit suite, race suite, lint, and vuln scan
  simultaneously in the background exhausted the host's Windows paging
  file, causing the race suite (ThreadSanitizer `mmap` failure) and lint
  (Go compiler `fork/exec` failure) to fail spuriously. Both passed
  cleanly on a serial retry.
- **Intermittent PowerShell `Process.Start`/nested-`cmd` flakiness invoking
  `rein.exe` (part A).** Confirmed the binary itself was unaffected; the
  reliable pattern found was plain `& $R args *> file`, retrying
  individually on the rare flake.
- **Live host Codex account usage-limit exhaustion (part A, also `G1`
  above).** Reproduced on 3 independent live-turn attempts across two
  installed Codex CLI versions; blocks any row (any executor's) needing a
  live Codex conversational turn until the account's limit resets.
  `--dry-run` rows are unaffected once an in-range CLI is placed first on
  `PATH`.
- **Codex CLI version drift (parts A, B, D; also `codex:E1`–`E3` above).**
  The default, PATH-first Codex CLI reports `0.153.4`, above the verified
  ceiling `0.149.0`. `rein`'s own version gate correctly refuses
  live-mechanism rows against it — the documented "read the refusal
  correctly" case, not a defect. A second, in-range install (`0.146.0`)
  was used for dry-run-only evidence.
- **`push --all` with no `--agent` filter pushes every currently-configured
  agent's indexed sessions, not only the intended T5 three, unless every
  other agent's home is also isolated (part B).** Caught before scoring;
  corrected by using `push --agent <a> --all` per agent. No plaintext left
  the process.
- **`conptydriver` launched via `Start-Process -FilePath <exe>` resolves a
  vendor CLI's bare name via `CreateProcess`, which does not do
  `cmd.exe`-style `PATHEXT` extension search (part B).** Real launchers
  needed the explicit extension (`claude.cmd`, `codex.cmd`, `grok.exe`) or
  the child silently failed to spawn.
- **Windows batch shim scripts (`.cmd`) for version-range E4/E6 tests must
  escape a literal `)` inside an `if (...) ( ... )` block (part B).** An
  unescaped `)` silently truncated the shim's own `--version` output.
- **`REINSTATE_PASSPHRASE_FD` cannot be wired from Git Bash's own `<()`
  process substitution against a native Windows `rein.exe` (part B).** A
  small Go helper using `SetHandleInformation`/`AdditionalInheritedHandles`
  (the same pattern `scripts/testing/hoplab/secretfd_windows.go` already
  uses) was needed.
- **S3-compatible credentials for `rein init`/`push`/`pull` are
  `REINSTATE_S3_ACCESS_KEY_ID`/`REINSTATE_S3_SECRET_ACCESS_KEY`, not the
  `AWS_`-prefixed names (part B).** Worth stating explicitly in the T5
  testing docs; the AWS-named variables fail silently with a generic
  "credential rejected."
- **`conptydriver.exe` invoked directly from an automation shell (piped
  stdout) needs a genuine new console, matching the driver README's own
  documented trap (part C).** Resolved via `Start-Process` without stdio
  redirection; no product impact.
- **`hoplab`'s push path applies an "unmapped project" filter for Codex and
  Claude pushes (part D, carried since `v0.6.0-rc.5`'s `H4`).** A session
