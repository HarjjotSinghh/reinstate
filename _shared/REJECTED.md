# REJECTED

> **The most important file in this repo.**
>
> Every time Harjot rejects or edits a draft, an entry is appended here containing:
> 1. the draft, verbatim
> 2. his edit or reason, verbatim
> 3. the rule it should become
>
> **Every bot reads this file before drafting.** This is how the fleet stops repeating mistakes.
>
> Append-only. Entries are never deleted or reworded. If a rule is superseded, add a new entry saying so.
